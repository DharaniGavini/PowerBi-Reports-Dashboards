# 🎬 Movie Sales Analysis Dashboard | Power BI

## 📌 Project Overview
Developed an interactive Movie Sales Analysis Dashboard using
Microsoft Power BI to analyze box office revenue, IMDb ratings,
movie genres, audience engagement, and industry trends.

The project consists of four dashboards that provide insights
into movie performance, revenue trends, and audience preferences.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Exploratory Data Analysis (EDA)

## 📊 Dashboard 1: Movie Sales Analysis
- Analyzed yearly movie releases and box office revenue trends.
- Visualized average IMDb ratings and audience votes over time.
- Examined movie runtime and production trends.

## 📊 Dashboard 2: Genre & Rating Analysis
- Analyzed movie distribution across different genres.
- Compared IMDb ratings and Metascores by genre.
- Identified top revenue-generating movie genres.
- Analyzed audience engagement across genres.

## 📊 Dashboard 3: Top Performers & Box Office Insights
- Identified top-performing movies and directors.
- Analyzed director-wise box office revenue.
- Visualized movies with the highest audience votes.
- Compared movie ratings and revenue performance.

## 📊 Dashboard 4: Correlation & Advanced Metrics
- Examined relationships between IMDb ratings and revenue.
- Analyzed movie runtime and box office performance.
- Compared revenue trends across genres and years.
- Created KPI cards for average revenue, Metascore, and runtime.

## 📈 Key Insights
- Box office revenue generally increased over the analyzed years.
- Adventure and Action were among the highest revenue-generating genres.
- The Dark Knight, Inception, and Interstellar received high audience engagement.
- Movie ratings and revenue showed varying relationships across genres.
- Movie runtime and genre influenced performance patterns differently.

## 🎯 Project Outcome
Developed four interactive Power BI dashboards to transform
movie data into meaningful visual insights, demonstrating
data analysis, KPI reporting, and business intelligence skills.
